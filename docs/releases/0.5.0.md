## New: tasks and timeline in one LLR view

- Switch between the task list and a read-only timeline using the clock/list button. The task list keeps its estimates and existing task operations; it does not show memo items.
- Review completed activities across daily notes. Press an activity to expand its summary in place, including recorded times and notes. Collapse it again, or expand/collapse all loaded summaries from the header. Links open their linked notes separately.
- Use the date picker, previous/next day, or Today to move the display. The paper button opens the displayed day’s daily note separately.
- Shared spacing, typography and controls make both views easier to read in a sidebar. Timeline hour labels have their own lane, with numbers every two hours. Mobile date selection uses the native input directly.

## Other fixes since 0.4.2

- Obsidian property checkboxes no longer trigger Markdown task actions.
- Japanese whole-hour routine sections such as `午後7時` are recognized.

## Compatibility and updating

- Update LLR through Obsidian Community Plugins or BRAT. Minimum Obsidian version remains 1.7.2; desktop and mobile are supported.
- Records remain in Markdown. No record migration or separate database is required. Existing LLR panes are consolidated into the shared task/timeline view.
- The timeline shows completed timed records and their notes; unfinished tasks and the SRS area are excluded by default. It keeps the 03:00 day boundary. The task view keeps its midnight boundary.
- Selecting a date only changes the display. Opening that day’s note requires the core Daily Notes plugin; dates other than today open an existing note and do not create a missing one.
- `EST. FINISH` shows the remaining work’s finish estimate without adding sleep. Sleep-aware calculations are retained internally.
