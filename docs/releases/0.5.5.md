## Mobile checkboxes and daily note updates

- Tapping a task checkbox on mobile now uses the checkbox that received the tap, even when the device reports coordinates over nearby text.
- Releasing a long press after the task changes state no longer triggers a second, short-press action.
- Daily routine insertion preserves edits saved while LLR prepares the routine list.
- Completing or rescheduling a routine while editing the daily note no longer writes the result onto a different task line.

Update through Obsidian Community Plugins or BRAT. Minimum Obsidian version is 1.7.2.
