## Mobile sidebar fixes

- Task duration bars now use the available text width on mobile, removing excessive blank space on the right. Times and scheduled times share a row above the bar; the existing 120-minute scale is retained.
- Mobile activity names and estimate values use at least 17px text, with times and supporting labels at least 13px. Long task names can wrap to two lines.
- Extra bottom scrolling space keeps the final task and timeline records clear of Obsidian’s floating navigation fade.
- Desktop layout, task operations and Markdown records are unchanged.

## Updating

Update LLR through Obsidian Community Plugins or BRAT. Minimum Obsidian version remains 1.7.2. No data migration is required.
