## Highlights

- A routine can now appear in multiple daily sections. Set `section: [700, 1900]` to expand the same routine under both section headings while keeping one routine note as the source.
- Repeating routines no longer require an initial `next_due`. LLR derives the first effective due date from `repeat` and writes `next_due` after completion.
- Future daily notes are preview-safe: opening, inserting, or checking tasks in a future note does not advance the routine source state.

## Improvements and fixes

- Running tasks that fall outside their planned section are positioned more consistently in the Summary View.
- Frontmatter repair no longer consumes Markdown body content when the closing delimiter is missing.
- Restored the grace period used to cancel an accidental routine completion.
- Checkbox clicks outside daily notes are left to Obsidian instead of being intercepted by LLR. Thanks to @mutatsu for the report and proposed fix in [PR #1](https://github.com/goryugocast/llr/pull/1).
- Non-Markdown views no longer receive an unsupported Summary View refresh call, preventing the reported Excalidraw startup failure. Thanks to @kuretivivente for [Issue #2](https://github.com/goryugocast/llr/issues/2).

## Compatibility

- Minimum Obsidian version remains 1.7.2.
- Desktop and mobile builds are included.
