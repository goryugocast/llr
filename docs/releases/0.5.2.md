## Mobile header and date navigation

- The task and timeline headers share a left-aligned date, weekday and small chevron. Action icons stay directly accessible on the right, with separate 44px touch targets.
- Mobile date selection opens the native date picker directly, without an intermediate dialog. Desktop keeps its existing date picker, Today and previous/next-day controls.
- Choosing a date in the shared LLR pane opens that day’s daily note and aligns the sidebar to the same date. A missing past note is not created; the current note and sidebar date are retained. Cancelling date selection keeps the current date.

## Optional diagnostics

- Timeline diagnostic recording can be started and stopped from the command palette. It is off by default and after plugin reload. Logs stay in the vault and omit note paths, task titles and note text.
- This release does not claim a root-cause fix for timeline date jumps.

## Updating

Update LLR through Obsidian Community Plugins or BRAT. Minimum Obsidian version remains 1.7.2. No data migration is required. Opening daily notes requires the core Daily Notes plugin.
